# Dhiraj Chandel — Developer Portfolio

Pure **React + Vite + TypeScript + Tailwind CSS v4 + Framer Motion + React Icons** static portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

Outputs to `dist/` — a static folder with `index.html` + `assets/`.
Deploy directly to Netlify, Vercel, GitHub Pages, Hostinger, cPanel, or any static host.

## Preview the production build

```bash
npm run preview
```

## Edit content

All copy, projects, skills, and links live in `src/data/portfolio.ts`.
The hero visual lives at `src/assets/developer-workspace.jpg`.
